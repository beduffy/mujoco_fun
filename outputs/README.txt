Artifacts generated by the headless PyBullet suite

Locations
- MP4 videos: /workspace/outputs/
- GIF previews: /workspace/outputs/gifs/
- PNG screenshots: /workspace/outputs/screens/
- HTML gallery: /workspace/outputs/index.html

Ways to view
1) Using a local HTTP server (recommended for quick preview):
   python3 -m http.server 8000 --directory /workspace/outputs
   Then open http://localhost:8000/index.html

2) Download artifacts:
   - Single bundle: /workspace/outputs_bundle.tar.gz
   - Or individual files from the paths above.

3) IDE File Browser:
   Open the Files panel and navigate to /workspace/outputs/ to open or download files.

Notes
- Videos are recorded at 720x480 and ~30 fps.
- TinyRenderer is used for maximum headless compatibility.
- If you regenerate artifacts, re-run the GIF exporter: python3 tools/export_gifs.py
